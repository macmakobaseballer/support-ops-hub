## 遷移図

```mermaid
flowchart TD
    SCR01["**SCR-01**\nログイン"]

    subgraph APP["ログイン後（共通レイアウト：サイドバー＋ヘッダー）"]
        SCR02["**SCR-02**\nダッシュボード"]
        SCR03["**SCR-03**\n問い合わせ一覧"]
        SCR04["**SCR-04**\n問い合わせ詳細"]
        SCR05(["**SCR-05**\n問い合わせ登録・編集\n〔モーダル〕"])
        SCR06["**SCR-06**\n顧客レポート"]
        SCR07["**SCR-07**\nシステムダッシュボード"]

        subgraph MASTER["マスタ管理（管理者のみ）"]
            SCR08["**SCR-08**\n顧客企業マスタ"]
            SCR09(["**SCR-09**\n顧客企業登録・編集\n〔モーダル〕"])
            SCR10["**SCR-10**\nシステムマスタ"]
            SCR11(["**SCR-11**\nシステム登録・編集\n〔モーダル〕"])
            SCR12["**SCR-12**\nユーザー管理"]
        end
    end

    %% 認証
    SCR01 -->|"ログイン成功"| SCR02
    SCR02 -.->|"ログアウト"| SCR01

    %% ダッシュボード → 一覧
    SCR02 -->|"ステータスカード\n（新規・対応中・確認待ち）クリック"| SCR03

    %% 一覧 → 詳細
    SCR03 -->|"行クリック"| SCR04

    %% 詳細のアクション
    SCR04 -->|"「{システム名} 一覧へ」ボタン"| SCR07
    SCR04 -->|"「編集」ボタン"| SCR05
    SCR04 -->|"ステータス変更ボタン\n（対応開始・完了など）"| SCR04

    %% モーダル：問い合わせ登録・編集
    SCR05 -->|"保存"| SCR04
    SCR05 -->|"キャンセル"| SCR04

    %% システムダッシュボード
    SCR07 -->|"行クリック"| SCR04
    SCR07 -->|"「新規登録」ボタン"| SCR05

    %% 新規登録保存後はシステムダッシュボードへ
    SCR05 -.->|"新規登録保存"| SCR07

    %% マスタ管理
    SCR08 -->|"「顧客企業追加」ボタン"| SCR09
    SCR08 -->|"「編集」ボタン"| SCR09
    SCR09 -->|"保存 / キャンセル"| SCR08

    SCR10 -->|"「システム追加」ボタン"| SCR11
    SCR10 -->|"「編集」ボタン"| SCR11
    SCR11 -->|"保存 / キャンセル"| SCR10

    %% サイドバーによるナビゲーション（全ページから）
    NAV["サイドバーナビ\n（全ページ共通）"]
    NAV -->|"ダッシュボード"| SCR02
    NAV -->|"問い合わせ一覧"| SCR03
    NAV -->|"顧客企業名クリック"| SCR06
    NAV -->|"システム名クリック"| SCR07
    NAV -->|"顧客企業（マスタ管理）"| SCR08
    NAV -->|"システム（マスタ管理）"| SCR10
    NAV -->|"ユーザー管理"| SCR12
```
