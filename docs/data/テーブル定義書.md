## 共通事項

- データベース: MySQL 8.0
- ストレージエンジン: `InnoDB`
- 文字セット: `utf8mb4`
- 照合順序: `utf8mb4_unicode_ci`
- 全テーブルに `created_at`（`DEFAULT CURRENT_TIMESTAMP`）を持つ
- 更新を伴うテーブルには `updated_at`（`DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP`）を持つ
- ENUM値の詳細は [データ定義.md](./データ定義.md) を参照

## customers

顧客企業マスター。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | `BIGINT` | NOT NULL | AUTO_INCREMENT | 主キー |
| `name` | `VARCHAR(255)` | NOT NULL | - | 顧客企業名（システム全体でユニーク） |
| `notes` | `TEXT` | NULL | NULL | 備考 |
| `is_active` | `TINYINT(1)` | NOT NULL | `1` | 有効フラグ（1:有効 / 0:無効） |
| `created_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | 作成日時 |
| `updated_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` | 更新日時 |

**制約:**
- PRIMARY KEY: `id`
- UNIQUE: `name`

**インデックス:**
- `PRIMARY KEY (id)`
- `UNIQUE KEY uk_customers_name (name)`
- `INDEX idx_customers_is_active (is_active)` — 有効顧客フィルタ用

## systems

システムマスター。顧客企業に紐づく。システム名は同一顧客内でユニーク。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | `BIGINT` | NOT NULL | AUTO_INCREMENT | 主キー |
| `name` | `VARCHAR(255)` | NOT NULL | - | システム名 |
| `customer_id` | `BIGINT` | NOT NULL | - | 顧客企業ID（FK → customers.id） |
| `description` | `TEXT` | NULL | NULL | システム説明 |
| `is_active` | `TINYINT(1)` | NOT NULL | `1` | 有効フラグ |
| `created_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | 作成日時 |
| `updated_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` | 更新日時 |

**制約:**
- PRIMARY KEY: `id`
- UNIQUE: `(customer_id, name)` — 同一顧客内でシステム名重複不可
- FOREIGN KEY: `customer_id` → `customers(id)`（顧客削除時は制約エラー）

**備考:** `customer_id` は登録後変更不可（画面仕様 SCR-11 より）

**インデックス:**
- `PRIMARY KEY (id)`
- `UNIQUE KEY uk_systems_customer_name (customer_id, name)`
- `INDEX idx_systems_is_active (is_active)`

## users

ユーザーマスター（担当者・管理者）。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | `BIGINT` | NOT NULL | AUTO_INCREMENT | 主キー |
| `name` | `VARCHAR(255)` | NOT NULL | - | 氏名 |
| `email` | `VARCHAR(255)` | NOT NULL | - | メールアドレス（ログインID） |
| `password_hash` | `VARCHAR(255)` | NOT NULL | - | bcryptハッシュ化済みパスワード |
| `role` | `ENUM('admin','member')` | NOT NULL | `'member'` | ロール |
| `is_active` | `TINYINT(1)` | NOT NULL | `1` | 有効フラグ |
| `created_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | 作成日時 |
| `updated_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` | 更新日時 |

**制約:**
- PRIMARY KEY: `id`
- UNIQUE: `email`

**インデックス:**
- `PRIMARY KEY (id)`
- `UNIQUE KEY uk_users_email (email)`
- `INDEX idx_users_is_active (is_active)`

## system_assignees

システムの担当者プールを管理する中間テーブル（systems と users の M:N）。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `system_id` | `BIGINT` | NOT NULL | - | システムID（FK → systems.id） |
| `user_id` | `BIGINT` | NOT NULL | - | ユーザーID（FK → users.id） |

**制約:**
- PRIMARY KEY: `(system_id, user_id)`
- FOREIGN KEY: `system_id` → `systems(id)` ON DELETE CASCADE
- FOREIGN KEY: `user_id` → `users(id)` ON DELETE CASCADE

**インデックス:**
- `PRIMARY KEY (system_id, user_id)`
- `INDEX idx_system_assignees_user_id (user_id)` — ユーザー削除時の逆引き用

## tickets

チケット（問い合わせ本体）。システムの中心となるテーブル。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | `BIGINT` | NOT NULL | AUTO_INCREMENT | 主キー |
| `title` | `VARCHAR(255)` | NOT NULL | - | タイトル |
| `description` | `TEXT` | NULL | NULL | 問い合わせ内容 |
| `type` | `ENUM('question','bug','config','data')` | NOT NULL | - | 種別 |
| `priority` | `ENUM('high','medium','low')` | NOT NULL | - | 優先度 |
| `status` | `ENUM('new','in_progress','waiting','done')` | NOT NULL | `'new'` | ステータス |
| `customer_id` | `BIGINT` | NOT NULL | - | 顧客企業ID（FK → customers.id） |
| `system_id` | `BIGINT` | NOT NULL | - | システムID（FK → systems.id） |
| `assignee_id` | `BIGINT` | NULL | NULL | 担当者ID（FK → users.id）省略可 |
| `created_by` | `BIGINT` | NOT NULL | - | 作成者ID（FK → users.id） |
| `received_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | 受付日時（手動変更可） |
| `created_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | 作成日時 |
| `updated_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP` | 更新日時 |

**制約:**
- PRIMARY KEY: `id`
- FOREIGN KEY: `customer_id` → `customers(id)`
- FOREIGN KEY: `system_id` → `systems(id)`
- FOREIGN KEY: `assignee_id` → `users(id)` ON DELETE SET NULL
- FOREIGN KEY: `created_by` → `users(id)`

**インデックス:**
- `PRIMARY KEY (id)`
- `INDEX idx_tickets_status (status)` — ステータスフィルタ
- `INDEX idx_tickets_priority (priority)` — 優先度フィルタ
- `INDEX idx_tickets_type (type)` — 種別フィルタ
- `INDEX idx_tickets_customer_id (customer_id)` — 顧客別集計
- `INDEX idx_tickets_system_id (system_id)` — システム別集計・フィルタ
- `INDEX idx_tickets_assignee_id (assignee_id)` — 担当者フィルタ
- `INDEX idx_tickets_received_at (received_at DESC)` — デフォルトソート

## comments

チケットに対するコメント（対応履歴）。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | `BIGINT` | NOT NULL | AUTO_INCREMENT | 主キー |
| `ticket_id` | `BIGINT` | NOT NULL | - | チケットID（FK → tickets.id） |
| `author_id` | `BIGINT` | NOT NULL | - | 投稿者ID（FK → users.id） |
| `body` | `TEXT` | NOT NULL | - | コメント本文 |
| `created_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | 投稿日時 |

**制約:**
- PRIMARY KEY: `id`
- FOREIGN KEY: `ticket_id` → `tickets(id)` ON DELETE CASCADE
- FOREIGN KEY: `author_id` → `users(id)`

**インデックス:**
- `PRIMARY KEY (id)`
- `INDEX idx_comments_ticket_id (ticket_id)` — チケット別コメント取得

## ticket_history

チケットのフィールド変更履歴（監査ログ）。変更1件ごとに1レコードを記録する。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | `BIGINT` | NOT NULL | AUTO_INCREMENT | 主キー |
| `ticket_id` | `BIGINT` | NOT NULL | - | チケットID（FK → tickets.id） |
| `changed_by` | `BIGINT` | NOT NULL | - | 変更者ID（FK → users.id） |
| `field_name` | `VARCHAR(100)` | NOT NULL | - | 変更されたフィールド名 |
| `old_value` | `TEXT` | NULL | NULL | 変更前の値 |
| `new_value` | `TEXT` | NULL | NULL | 変更後の値 |
| `changed_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | 変更日時 |

**制約:**
- PRIMARY KEY: `id`
- FOREIGN KEY: `ticket_id` → `tickets(id)` ON DELETE CASCADE
- FOREIGN KEY: `changed_by` → `users(id)`

**インデックス:**
- `PRIMARY KEY (id)`
- `INDEX idx_ticket_history_ticket_id (ticket_id)` — チケット別履歴取得

**field_name の値例:**
- `status`, `priority`, `assignee_id`, `title`, `description`, `type`, `received_at`

## attachments

チケットの添付ファイル。ファイル実体はS3に保存し、本テーブルはメタデータとS3キーを管理する。

| カラム名 | データ型 | NULL | デフォルト | 説明 |
|---|---|---|---|---|
| `id` | `BIGINT` | NOT NULL | AUTO_INCREMENT | 主キー |
| `ticket_id` | `BIGINT` | NOT NULL | - | チケットID（FK → tickets.id） |
| `uploaded_by` | `BIGINT` | NOT NULL | - | アップロード者ID（FK → users.id） |
| `file_name` | `VARCHAR(255)` | NOT NULL | - | 元のファイル名 |
| `file_key` | `VARCHAR(512)` | NOT NULL | - | S3オブジェクトキー |
| `file_size` | `INT` | NOT NULL | - | ファイルサイズ（バイト） |
| `content_type` | `VARCHAR(100)` | NOT NULL | - | MIMEタイプ（例: `image/png`） |
| `created_at` | `DATETIME` | NOT NULL | `CURRENT_TIMESTAMP` | アップロード日時 |

**制約:**
- PRIMARY KEY: `id`
- FOREIGN KEY: `ticket_id` → `tickets(id)` ON DELETE CASCADE
- FOREIGN KEY: `uploaded_by` → `users(id)`

**インデックス:**
- `PRIMARY KEY (id)`
- `INDEX idx_attachments_ticket_id (ticket_id)` — チケット別添付取得
