## 概要

本文書では、MySQL の `ENUM` 型として定義する列挙値と、アプリケーション全体で共有するデータ定義を定める。
バックエンド（Go）のコード定義およびフロントエンド（Nuxt.js）のUI表現と対応させること。

---

## 1. チケットステータス（ticket_status）

チケットの対応状態を表す。

| 値 | 表示名（日本語） | 説明 |
|---|---|---|
| `new` | 新規受付 | 受付済み・未着手 |
| `in_progress` | 対応中 | 担当者が作業中 |
| `waiting` | 確認待ち | 顧客の返答を待っている状態 |
| `done` | 完了 | 対応完了 |

### ステータス遷移ルール

```
new → in_progress → waiting → done
               ↑______________|
```

| 現在のステータス | 遷移可能なステータス | 画面上のアクション |
|---|---|---|
| `new` | `in_progress` | 対応開始する |
| `in_progress` | `waiting` / `done` | 確認待ちへ / 完了にする |
| `waiting` | `in_progress` / `done` | 対応再開する / 完了にする |
| `done` | なし（終端） | ― |

### バッジスタイル

| 値 | 背景色 | 文字色 |
|---|---|---|
| `new` | `#dbeafe` | `#1d4ed8` |
| `in_progress` | `#f5ede4` | `#7c4d33` |
| `waiting` | `#ede9fe` | `#7c3aed` |
| `done` | `#dcfce7` | `#166534` |

## 2. チケット優先度（ticket_priority）

| 値 | 表示名（日本語） | 背景色 | 文字色 |
|---|---|---|---|
| `high` | 高 | `#fee2e2` | `#dc2626` |
| `medium` | 中 | `#fef3c7` | `#b45309` |
| `low` | 低 | `#f0fdf4` | `#166534` |

### 種別による優先度デフォルト値

チケット登録時、種別を選択すると優先度が自動設定される（手動変更可）。
**この自動設定はフロントエンド（Nuxt.js）側で行う。バックエンドはリクエストで受け取った値をそのまま保存し、デフォルト値の補完は行わない。**

| 種別（ticket_type） | デフォルト優先度 |
|---|---|
| `bug` | `high` |
| `question` | `medium` |
| `config` | `medium` |
| `data` | `medium` |

## 4. ユーザーロール（user_role）

| 値 | 表示名（日本語） | 権限概要 |
|---|---|---|
| `admin` | 管理者 | 全機能にアクセス可（チケット・マスター管理・ユーザー管理） |

## 5. チケット変更履歴 フィールド名定義（ticket_history.field_name）

`ticket_history` テーブルの `field_name` カラムに記録される値と、フロントエンドでの表示名の対応。

| field_name 値 | 表示名（日本語） | 記録タイミング |
|---|---|---|
| `status` | ステータス | `PATCH /tickets/{id}/status` 実行時 |
| `assignee_id` | 担当者 | `PATCH /tickets/{id}/assignee` 実行時 |
| `priority` | 優先度 | `PUT /tickets/{id}` で priority が変更された時 |
| `title` | タイトル | `PUT /tickets/{id}` で title が変更された時 |
| `description` | 詳細内容 | `PUT /tickets/{id}` で description が変更された時 |
| `type` | 種別 | `PUT /tickets/{id}` で type が変更された時 |
| `received_at` | 受付日時 | `PUT /tickets/{id}` で received_at が変更された時 |

**実装方針：**
- `old_value` / `new_value` はそれぞれ変更前後の値を文字列で保存する
- `assignee_id` の場合は値としてユーザーIDを保存する（ユーザー名ではなくID）
- フロントエンドは `field_name` をこの表に従って日本語表示名に変換して表示する
