## 概要

本文書では、MySQL の `ENUM` 型として定義する列挙値と、アプリケーション全体で共有するデータ定義を定める。
バックエンド（Go）のコード定義およびフロントエンド（Nuxt.js）のUI表現と対応させること。

---

## 1. チケットステータス（ticket_status）

チケットの対応状態を表す。

| 値 | 表示名（日本語） | 説明 |
|---|---|---|
| `new` | 新規問い合わせ | 受付済み・未着手 |
| `in_progress` | 対応中 | 担当者が作業中 |
| `awaiting` | 確認待ち | 顧客の返答を待っている状態 |
| `complete` | 完了 | 対応完了 |

### ステータス遷移ルール

```
new → in_progress → awaiting → complete
                ↑_______________|
complete → in_progress（再オープン）
```

| 現在のステータス | 遷移可能なステータス | 画面上のアクション |
|---|---|---|
| `new` | `in_progress` | 対応開始 |
| `in_progress` | `awaiting` / `complete` | 確認待ちにする / 完了にする |
| `awaiting` | `in_progress` / `complete` | 対応再開 / 完了にする |
| `complete` | `in_progress` | 再オープン |

### バッジスタイル

| 値 | 背景色 | 文字色 |
|---|---|---|
| `new` | `#dbeafe` | `#1d4ed8` |
| `in_progress` | `#f5ede4` | `#7c4d33` |
| `awaiting` | `#ede9fe` | `#7c3aed` |
| `complete` | `#dcfce7` | `#166534` |

## 2. チケット優先度（ticket_priority）

| 値 | 表示名（日本語） | 背景色 | 文字色 |
|---|---|---|---|
| `high` | 高 | `#fee2e2` | `#dc2626` |
| `medium` | 中 | `#fef3c7` | `#b45309` |
| `low` | 低 | `#f0fdf4` | `#166534` |

### 種別による優先度デフォルト値

チケット登録時、種別を選択すると優先度が自動設定される（手動変更可）。

| 種別（ticket_type） | デフォルト優先度 |
|---|---|
| `bug` | `high` |
| `question` | `medium` |
| `config_change` | `medium` |
| `data_correction` | `medium` |

## 3. チケット種別（ticket_type）

| 値 | 表示名（日本語） |
|---|---|
| `question` | 操作方法の質問 |
| `bug` | バグ報告 |
| `config_change` | 設定変更依頼 |
| `data_correction` | データ修正依頼 |

## 4. ユーザーロール（user_role）

| 値 | 表示名（日本語） | 権限概要 |
|---|---|---|
| `admin` | 管理者 | 全機能にアクセス可（チケット・マスター管理・ユーザー管理） |
| `staff` | スタッフ | チケット操作・閲覧のみ（マスター管理不可） |

### ロール別アクセス権限

| 機能 | admin | staff |
|---|---|---|
| チケット一覧・詳細閲覧 | ✅ | ✅ |
| チケット登録・編集 | ✅ | ✅ |
| ステータス変更 | ✅ | ✅ |
| ダッシュボード・レポート | ✅ | ✅ |
| 顧客マスター管理 | ✅ | ❌ |
| システムマスター管理 | ✅ | ❌ |
| ユーザー管理（閲覧のみ） | ✅ | ❌ |
